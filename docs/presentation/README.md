Déroulé, en 15 à 20 minutes :

1. le projet (diapositives 1 à 3) ;
2. la démonstration, avec le scénario du cahier (4) ;
3. la technique : architecture, chaîne WebXR, patrons, séquence animée (5 à 8) ;
4. la qualité : performance, PWA, tests (9 à 11) ;
5. le bilan et ce qui reste à mesurer sur téléphone (12 et 13).

La démonstration en direct se place après la diapositive 4, ou à sa place ; la dernière diapositive porte le QR code de l'application.

Les chiffres viennent du dépôt : tests du 17 novembre 2026, mesures du [sprint 6](../sprint-6.md) et [matrice de conformité](../conformite.md). Aucun résultat sur téléphone n'y est donné pour la version finale.

La présentation reprend le style de celle de l'état de l'art. Elle a été produite par un script pptxgenjs, puis vérifiée dans PowerPoint : voir [ATTRIBUTION.md](../../ATTRIBUTION.md).
