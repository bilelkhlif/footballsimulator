Bienvenue sur le tableau tactique

  1. Déplacer : touchez un joueur ou le ballon, puis sa nouvelle place.
  2. Passe : touchez le ballon ou son porteur, puis un partenaire ou un espace libre.
  3. Course : touchez un joueur, puis son point d’arrivée.
  4. L’aperçu devient rouge quand une action est impossible. Annuler défait la dernière action.

Au clavier : D, P, C pour les outils ; Échap abandonne ; Ctrl+Z annule.
